# FeeEye 自动化运营第二十三阶段：反馈内容诊断

日期：2026-09-04。Phase 22 把达到门槛的用户反馈转换为证据路由。本阶段在不联网、不修改内容的前提下，自动检查对应文章的中英结构、来源inventory、复核日期、检查清单、警示、自测和相关工具。

结构诊断会记录中英两版的章节、学习目标、自测、段落、要点、检查清单和风险警示数量，并检查两版结构是否对齐。详细结果、来源URL和文章ID只保存在 AES-256-GCM 加密记录中。

诊断严格区分可内部确定与必须外部验证的项目：

- 中英结构、检查清单和工具连接可从当前代码确定。
- 链接状态和重定向链必须另行只读HTTP验证。
- 内容过时必须回到一手官方来源核对发布日期、适用范围和矛盾说明。
- 缺少步骤、表述不清和范围问题必须进行语义复核，不能只靠字数或句长自动改写。

工作流只在 `FEEEYE_FEEDBACK_DIAGNOSTICS=enabled` 时于每周一 03:27 UTC 定时执行。它仅读取加密修订计划并生成新的加密诊断，不持有Google、Cloudflare或X凭据。在外部证据完成前，修订草稿、内容补丁、PR和发布全部禁止。
