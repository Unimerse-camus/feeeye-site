# 竞对对比、行动总结与下一步规划（2026-08-20）

## 本轮目标

完成三项改进：字段级官方来源与发布审计、统一提币费用模型、面向新手的条件化交易所决策器。暂不启用匿名统计，等待页面验收通过。

## 竞对产品对比

| 产品 | 核心优势 | 对新手的主要不足 | FeeEye 应学习/避免 |
|---|---|---|---|
| CoinGecko Exchanges | 162 家交易所覆盖；Trust Score有公开方法，综合流动性、网络安全、监管、事故和储备 | 更像数据排名页；用户仍需自己判断地区、费用路径和提币网络 | 学习统一口径和方法公开；不把综合分直接包装成“适合你” |
| CoinMarketCap Exchanges | 交易量、平均流动性、访问量、市场数、币种数和法币支持覆盖广 | 指标密度高，不能直接回答第一次小额买入和提币怎么选 | 保留规模/流动性证据，但后置到决策结论之后 |
| WithdrawFees | 从交易所API获取链级提现费和最低额度，通常数分钟更新；按币种、链和交易所检索 | 只解决提币费用；不处理地区、KYC、交易费、入金和安全事实 | 费用自动化是FeeEye最大数据短板，应优先建设；不要复制“最低费即最佳路线” |
| Finder | “Best for”标签、新手解释、费用/安全/易用性/支付方式并列；公开编辑筛选逻辑 | 以编辑榜单和长文章为主，用户金额和提币路径不会实时改变结论 | 学习通俗解释与方法披露；避免给所有用户一个“最佳” |
| NerdWallet | 公开评分权重；用固定金额测试交易和提现费用，便于横向比较 | 权重仍是统一模板，地区、具体网络和实际任务的个体差异有限 | 学习固定测试口径；FeeEye继续让金额、网络和任务由用户输入 |
| Swaps | 输入金额后展示可服务用户国家和支付方式的实时路线，接近“可执行路径” | 更偏买卖/兑换路由，不覆盖交易所长期安全与能力事实 | 是最值得跟踪的交互竞对；FeeEye应坚持研究和风险解释，不走直接交易聚合 |

## 本轮已完成

### 1. 字段级来源与发布审计

- 7 家交易所均增加交易费、提币费、KYC、牌照和储备的字段级官方来源及核验日期。
- 35个官方来源链接完成可达性检查；可公开访问或明确受官方反自动化限制，没有404链接。
- 页面直接提供来源链接，不再只显示一个全页更新时间。
- 抽取共享数据验证模块，生成器在数据契约错误时直接中止。
- 新增GitHub验证流程，检查数据、生成全部页面并拒绝 `undefined`、`NaN` 等损坏结果。
- Coinbase公开网络费全部明确建模为 `unknown`，不会按0费用或虚构固定费用参与胜负；Kraken按官方当前USDT网络费更新。
- 修正Bitget法国、德国和印度的2026年服务/新用户限制；受限但缺少交易所级记录的地区不再被推导成“全部不可用”。

### 2. 统一提币费用模型

- `fixed_snapshot`：交易所给出的固定费用快照。
- `dynamic_snapshot`：会随网络或交易所报价变化的费用快照。
- `unknown`：确认网络能力但没有可靠费用，不参与排名。
- `percentage_with_cap`：按提现金额收取并设上限的处理费。
- 全成本计算器、基础费率计算器、交易所详情页和两两对比页共用同一报价函数。

### 3. 新手决策器

用户只需回答：

1. 常住国家或地区；
2. 预计买入金额；
3. 立即成交或设价等待；
4. 是否提币；
5. 若提币，接收钱包支持的网络。

决策顺序：

1. 先检查交易所级地区记录；
2. 地区未知或不覆盖时不宣布胜负；
3. 再计算当前金额和成交方式的交易费；
4. 提币时叠加网络费和按金额处理费；
5. 明确排除入金费、价差和滑点，要求最终确认实时报价。

## 当前仍有的产品缺口

- 交易所提现费用主要是人工快照，刷新速度不及API型竞对。
- 国家可用性数据覆盖有限，受限地区只做“不下结论”，还不能提供完整本地产品判断。
- 没有实时入金报价、即时买币价差和滑点，所以不能宣称“真实总成本”。
- 只有7家交易所，规模远小于CoinGecko和CMC。
- 尚无FeeEye自身的用户行为和任务测试数据。

## 验收通过后的下一步规划

1. 接入交易所公开API或可审计采集任务，自动刷新USDT网络费、最低提现额和状态。
2. 将国家可用性拆成“全球品牌/本地实体/具体产品”三级，补齐官方Terms来源。
3. 用户登录Cloudflare后启用经过隐私审查的匿名事件，先跑7天基线。
4. 用5–8名真实新手测试“选所—买入—提币”任务，记录完成率、耗时和误解点。
5. 根据数据决定是否加入支付方式/价差报价；验收前不扩交易所数量、不增加新工具。
