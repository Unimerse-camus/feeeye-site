# FeeEye 工具库规划（Tools Roadmap）

> **来源**：在 2026-08-13《Crypto 工具调研与功能产品规划》基础上融合——
> - 用户痛点硬数据（CryptoAdventure 2025-12 / CryptoSafetyFirst 2026-07 / CryptoQuant 2024 / NordGloble 2026）
> - 8 工具 PRD + 3 阶段开发优先级（MVP→扩展→地区化）
> - 竞品空白与差异化（详见 docs/tools-competitor-research.md）
>
> **目标**：围绕币圈用户「算账 / 查数据 / 找交易所 / 避免被坑」的真实需求，建设工具矩阵作为站点流量引擎与转化层，
> 每个工具 = 免费价值 + 场景化 CTA，与程序化 SEO 页面（where-to-buy / compare / country）互相导流。
> 数据统一来自 `data/` 真相源（7 所官方费率 + CoinGecko 币种 + 公开 API），中英双语，零后端纯前端。

## 〇、用户痛点硬数据（为什么做这些工具）

| 痛点 | 数据 | 来源 | 直接解药 |
|---|---|---|---|
| **1. 费用不透明**（痛感最高） | 银行卡买 $1,000 ETH：用户以为 0.1%($1) 实际 3.4%($34)，**差 34 倍**；$20 提现：以为 $0.10 实际 $5，**差 50 倍** | CryptoAdventure 2025-12 | 全成本计算器 |
| **2. Gas 翻车**（损失最大） | $3,000 Gas 铸 NFT 失败 → 转走所有 ETH → 跨链后无目的地 Gas 币 → 资产卡死 | CryptoSafetyFirst 2026-07 | Gas 智能追踪（含跨链 Gas 提醒） |
| **3. 交易所选择困难**（投诉最多） | 1.出金受阻 2.账户无故冻结 3.关键时刻崩溃 4.隐藏费用 5.客服形同虚设 | NordGloble 2026 | 智能交易所对比（10 维度） |
| **4. 跨平台盈亏算不清** | 48% 用户同时用多个交易所，无工具能聚合总盈亏 | CryptoQuant 2024（1,478 人） | 跨平台盈亏聚合器 |
| **5. 合约爆仓价算不明** | "liquidation price calculator" 月搜索约 2 万次，中文"合约爆仓计算器"为中文区独有高频词 | SEO 数据 | 合约清算计算器 |
| **6. 链上成本不可见** | 空投猎人、DeFi 用户频繁链上交互，但不知道总 Gas 成本 | 用户调研 | Gas 智能追踪（操作成本估算） |

**竞品空白表**（机会）：
- 基础盈亏竞品已覆盖，但**全成本**（含入金/价差/滑点/提现）无人做 → T1
- Gas 价格显示已覆盖，但**"该不该操作"智能建议**无人做 → T4
- 费率对比已覆盖，但**多维度（出金/安全/KYC/流动性/合规）**无人做 → T2
- **中文站**是真实空白 → 全部工具 en+zh

## 二、统一架构规范（每个工具必须满足）

1. **单文件纯前端**：`tools/[tool].html` + `tools/[tool].zh.html`，vanilla JS，`window` 数据层（`../data/*.js`），零构建。
2. **中英双语**：zh 版 = 完整翻译（标题/标签/按钮/结果表/披露），页头带语言切换链接。
3. **页面互链**：
   - 工具 → where-to-buy / compare / country 页（数据延伸）
   - 首页工具矩阵卡片 → 各工具
   - sitemap 不含 tools（功能页，不进 SEO 索引流）
4. **数据时间戳**：显示 `last_updated`，注明"数据快照，交易前请核实"。

## 三、返佣嵌入通用原则（来自 PRD 第五部分）

> 这是所有工具 CTA 的通用红线，违反任何一条都破坏用户信任。

1. **工具必须 100% 可用**——即使不点返佣链接，工具完整可用（CTA 是便利，不是门槛）
2. **CTA 出现在决策时刻**——计算结果出来后，用户最需要"下一步行动"时（信任峰值）
3. **诚实标注返佣**——每个链接旁标注"返佣链接"（不欺骗用户）
4. **地区匹配**——大陆用户推 Bybit、港台用户推 Binance（KuCoin 欧盟 onboarding 暂停，跨境推广更灵活）
5. **不打扰**——CTA 放在结果下方，不弹窗、不强制、不覆盖结果

## 四、数据维护规范（来自 PRD 第四部分）

| 数据 | 更新频率 | 维护方式 | 成本 |
|---|---|---|---|
| 交易所费率 | **每周** | 手动核对官方页 + JSON 更新 | **30 分钟/周** ⚠️ |
| 提现费 | 每月 | 手动核对 | 20 分钟/月 |
| Gas 数据 | 实时 | API 自动（Etherscan/BscScan/各 RPC） | $0 |
| 币种价格 | 实时 | CoinGecko API（已有 fetch_coins.mjs 自动化） | $0 |
| 代币安全 | 实时 | GoPlus Security API（免费） | $0 |
| P2P 汇率 | 实时 | API + 缓存 | $0 |
| 安全/KYC/流动性 | 季度 | 手动核查 | 1 小时/季 |

**关键风险**：交易所费率**每周 30 分钟手动**——这是真实维护成本，**不是自动的**。CoinGecko 也不直接给精确费率表，需要每周打开 7 个交易所官方费率页核对 + 改 exchanges.js。建议设**周日提醒**专门维护。

## 七、与返佣扩展的协同

工具上线后会带动 affiliate 收入（CTA 转化）。明天你申请返佣后，把每所的实际批准佣金率回填 `ops/referral-tracker.md`，更新站点的多所 CTA 逻辑：
- 第 1 阶段：KuCoin（HODL100）作为主 CTA
- 申请回填后：按地区差异化推荐（大陆 ByBit、港台 Binance、T1 全成本结果中"最便宜的所"）
- 站点 CTA 切换到"按场景/地区推荐最优所"逻辑（数据驱动，不硬塞单一交易所）
