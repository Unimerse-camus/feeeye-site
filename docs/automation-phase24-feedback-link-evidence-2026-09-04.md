# FeeEye 自动化运营第二十四阶段：官方链接只读证据

日期：2026-09-04。Phase 23 已区分仓库内可确定的结构事实与需要外部验证的证据。本阶段只处理诊断中明确出现 `verify_links` 的已注册官方来源，没有候选时网络请求数必须为0。

只读请求默认使用 `HEAD`，服务器明确返回405或501时才用 `Range: bytes=0-0` 的有界 `GET` 备用。响应正文不读取、不保存，每次响应的body流立即取消。记录仅包含HTTP状态、最终官方地址、内容类型和是否发生重定向。

安全约束：

- 只允许 `LEARNING_SOURCES` 中已注册的HTTPS来源。
- 重定向后必须仍是同一官方主机，只容忍 `www` 差异。
- 单次最多12个去重链接，超限立即失败关闭。
- 详细URL和结果只写入 AES-256-GCM 加密回执，公开日志仅有通过/失败计数。
- 链接失败只会生成修复证据，不自动替换URL、改内容、建PR或发布。

工作流只在 `FEEEYE_FEEDBACK_LINK_EVIDENCE=enabled` 时于每周一 03:37 UTC 定时运行。它不持有Google、Cloudflare或X凭据，只在实际诊断需要链接证据时访问已注册官方URL。
